# Amazon 美国站 Listing 编写规范

更新时间：2026-11-12。此文档区分 Amazon 官方规则与公司写作约定。官方政策可能变化，生成前应核对目标站点、商品类型、后台字段提示及类目 Style Guide。

## Amazon 官方规则摘要

### 标题与 Item Highlights

- Amazon 官方公告说明，自 2026-07-27 起，除媒体类外各类别商品标题不超过 75 个字符（含空格）。
- Item Highlights 可用额外 125 个字符展示材料或推荐用途，公告称其可在搜索结果及详情页展示并可搜索。是否适用于目标商品，以对应类目和 Seller Central 实际字段为准。
- 标题须准确、清楚、简洁。标题、描述、要点和图片不得含价格、促销、可售状态、联系方式、外部订购链接、评论、推荐评价请求、广告宣传等违规内容。
- 通用详情页规则要求正常大小写，不可整字段全大写，不可在每个词开头使用 Emoji 或表情符号。
- 公司补充规则：标题以用户提供的品牌名开头。同一单词最多重复两次。标题与亮点采用主要单词首字母大写、介词小写的格式，尽量少用标点。关键词字段全部小写。
- 75 字符新规与 200 字符旧规则存在时间差异。按用户指定采用 2026-07-27 新规，并在执行时复核 Seller Central 是否有更细的类目规则。

### Bullet Points

- Amazon 帮助页说明可填写最多五条描述性要点，建议每条简洁聚焦一个特征及其利益。
- Amazon 通用规则页未给出适用于所有类别的统一 bullet 字符上限，实际字段限制须按类目模板或 Seller Central 校验。
- 公司写作规则要求每条尽量约 200 字符，最少五条、最多八条。平台字段若仅支持五条，则遵循平台实际字段限制，不能为满足内部条数要求而将多条内容塞入单一字段。
- 小标题可通过标点或大小写区分。内容以一个特征和对应买家利益为主，避免关键词堆砌和无意义重复。

### Product Description

- 用于补充商品特征、使用方式、规格和适用范围，内容须准确、清楚。
- 详情页规则禁止 HTML、JavaScript 或代码。Amazon 对描述中的换行有特例说明。
- 不加入价格、促销、评价、联系信息、站外链接或未经支持的产品宣称。

### Backend Search Terms / Generic Keywords

- 美国站官方 Search Optimization 页面规定 Generic Keyword 长度少于 250 bytes。
- 使用相关通用词、同义词和缩写，以空格分隔。建议小写，避免标点、重复、冠词介词等无效词，也不要重复其他字段已覆盖的信息。
- 品牌名、ASIN、冒犯性词等可能导致搜索词被删除或不采用。Amazon 不保证采用所有提交词。
- 公司规则：关键词字段全小写，并按查重阈值单独比对。

### 通用准确性要求

- 商品须准确分类和描述，不得误导消费者关于商品质量或特性。
- 不得添加电话号码、地址、邮箱、网址、外部购买链接、替代配送优惠、评论/推荐语、促销广告、时间敏感信息等规定不允许的内容。
- 类目 Style Guide、产品类型字段要求和商品详情页政策可能有补充规定，须在发布前核实。

## 公司 Listing 生成规则

- Title：按 2026-07-27 新规最多 75 字符（含空格），品牌名开头，同一单词最多两次。主要单词首字母大写，介词小写，少用标点。
- Item Highlights：若目标类目有此字段，最多 125 字符；主要单词首字母大写，介词小写，少用标点。不得重复标题堆字。
- Bullet Points：每条尽量约 200 字符，至少五条、最多八条。平台字段数量或长度限制优先按实际类目后台执行。小标题可以用标点或大小写区分。
- Description：补足规格、安装、适用场景和限制，避免重复堆词。
- Backend Search Terms：全小写，少于 250 bytes，尽量使用相关且未被其他字段覆盖的词。
- 所有字段须执行公司禁止词表全量命中检查。
- 防水、可移除按用户设置默认已验证。厚度、表面纹理缺失时向用户确认。耐热和抗菌当前不具备，除非用户明确提出仍须先核实具体语义和证据，不得描述为产品能力。
- 用户明确确认最终版本后再输出 Word 文档并纳入历史库。

## 最终审核要求

发布前逐字段检查产品事实、竞品归属、性能证据、公司禁词、限制性表达、夸大用语、场景适配、规格和安装方式一致性。每个发现都报告字段/位置、风险原因和修改建议，不能只报 Pass / Fail。详情页信息需准确可信，并符合目标站点和商品类型的政策及 Style Guide。
