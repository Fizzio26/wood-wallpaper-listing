# 木纹自粘墙纸产品知识库

## 资料性质

本库初始素材来自木纹listingGEO汇总.xlsx 的场景、人群、关键词、买家问题及 FAQ 建议，以及课件图片。大量内容是竞品问答、搜索假设或建议文案，并非自有 SKU 的已验证事实。

## 卖点记录字段

每条卖点应记录：卖点类别、产品事实、来源（自有资料/竞品资料/用户输入/研究推断）、真实性状态（已验证/待确认/仅竞品宣称）、适用条件、限制、可用英文表达、禁止夸大表达、对应 SKU、证据位置、复核日期。

## 初始分类

| 类别 | 研究素材 | 使用条件 |
|---|---|---|
| 功能 | 防水、防油、耐热、易清洁、遮盖轻微瑕疵 | 防水按用户规则已验证。油污、耐热、清洁和遮盖效果须有 SKU 依据。耐热当前产品不具备，禁止宣称。 |
| 材质 | PVC/乙烯基、膜厚、哑光/亮面、压纹、木纹视觉效果 | 厚度和表面纹理须由用户提供或确认。不得将仿木纹写成实木。 |
| 安装 | 自粘、网格底纸、导气槽、可重新定位、刮板/裁刀辅助 | 仅在该 SKU 实际具有相应结构或配件时使用。安装效果不得承诺零气泡、永不起边。 |
| 使用体验 | 测量、裁切、贴合、加热处理边角 | 加热操作须有安全和产品说明依据，不可衍生为产品耐热。 |
| 视觉 | 木纹颜色、纹理、空间风格 | 颜色、纹理和表面触感需与实物及图片一致。 |
| 限制 | 光滑、平整、清洁、干燥表面；纹理墙、炉灶附近、直接淋水区域等限制 | 按 SKU 说明确认，避免把竞品限制直接套用。 |

## 用户默认规则

- 可移除、防水：默认已验证。
- 厚度、表面纹理：用户在初始资料中提供，缺失时询问。
- 耐热、抗菌：产品目前不具备。除非用户明确提出，不得写入 Listing。

## 场景和搜索词

工作簿含厨房橱柜、柜门、抽屉、家具、台面、书架、桌面、租住房屋、宿舍、房车、DIY 翻新等候选场景，并提供 20 组英文搜索组合。表内已注明搜索组合属于搜索假设，尚无搜索量验证。场景只有在产品适用条件支持时才用于对应 SKU。

## 买家问题素材

常见问题包括是否像真实木材、是否有触感纹理、是否可移除、安装工具和气泡处理、厨房/浴室适用性、购买卷数、膜是否偏薄/易撕、深色底材是否透出、边缘翘起及如何移除。使用这些问题帮助组织信息，答案必须基于 SKU 资料。
